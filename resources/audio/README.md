# 掉包记 · 原创声音制作源

全部音符和音色由本目录代码离线合成；没有外部采样、录音或生成模型。

D0 的「换月谣」8 秒测试段：每音一秒，C5 E5 G5 A5 | E5 C5 A5 G5。第二句严格将第一句两两对调。主声为带指数衰减的三谐波拨弦，下方为 C3 低音；这是原文建议动机的本作实现，不引用已有旋律。

`voice()` 提供木板、铃、非整数泛音锣、种子噪声钹和拨弦。D0 导出两声杯音、一声识破锣与测试曲。PCM16 单声道；音乐 22050 Hz，音效 44100 Hz。输出按 RMS 归一并限制峰值，首尾归零。

```sh
npm run audio:build
npm run audio:check
```

数值通过不等于好听。实际听感记录放在 `artifacts/reports/d0-acceptance.md`。
