# 02 · 规则细则

所有数值都是初稿，**待原型验证**。数值写在 `content/data/`，代码里不写死。

## 1 全局流程

```text
标题 → 戏单（章节选择 / 继续）→ 序幕插画
  每一出：开场插画 →（形态解锁）→ 幕前查访 → 排练 ×2 → 岔路（路遇 / 抄小路）→ 对戏 → 谢幕 → 写信 → 梦 → 葛伦的铺子（升级、换印记）
第三出结束 → Demo 结尾 → 戏单（第四出预告）
```

第一出的顺序特殊：序幕插画 → 教学对戏 → 葛伦插画 → 查访（教学）→ 排练 ×2 → 谢幕。

## 2 戏台

### 2.1 站位【定】

- 戏台上一排 **5 个站位**，从左到右编号 1–5。
- 每个站位最多放一样东西：**阿鸣**、**对手**、**小怪**、**物件**，或者空着。
- 杯戏师飘在阿鸣身后，不占站位。
- 对手的戏灵站在对手身后，也不占站位（只是演出）。

### 2.2 东西的属性

| 属性 | 说明 |
|---|---|
| 生命 | 阿鸣、对手、小怪、部分物件有生命；降到 0 就"下台"（对手认输、小怪逃走、物件倒了），站位变空 |
| 不坏 | 没有生命的物件，挨打不受影响（攻击"打空"） |
| 重 | 不能被换位（例如石像、婆婆的摊位）。重的东西仍然可以挨打，按它自己的说明处理 |
| 持有物 | 手里拿着的一样东西（阿鸣的石子、老乔的灯笼），换物用 |
| 主人 | 物件属于谁（第二出用） |
| 隐身 | 不能被出手、弹珠、交换选中；意图照常公开显示 |

### 2.3 亮与暗（第三出起）

- 一个站位是"亮"的：这个站位或相邻站位上有**亮着的光源**（亮的灯柱、手里拿着亮灯的人）。
- 其它站位是"暗"的。站位的亮暗直接画在台面上（亮的站位有一圈暖色光）。
- 亮暗只在第三出起作用（老乔在暗处隐身）。

## 3 对戏的回合【定】

```text
对戏开始：开幕演出 → 词签填进水牌 → 对手公开第一个意图
┌ 你的回合
│ 1 清除你的守护
│ 2 触发「回合开始」效果
│ 3 行动：主行动最多 1 次 + 交换最多 1 次，顺序随意（可以先换后打，也可以先打后换）
│ 4 点「结束」
├ 对手回合
│ 5 清除对手和小怪的守护
│ 6 意图按头顶的编号 ①②③ 依次结算
│ 7 触发「回合结束」效果（规则相关的检查在这里）
│ 8 每个对手和小怪决定并公开下一个意图
└ 回到 1
```

- 主行动和交换都可以不用。
- 对手生命降到 0 的瞬间立即胜利，剩下的意图不再执行，台上剩下的小怪逃走。
- 序幕战没有对手，打倒所有月屑即胜利。
- 阿鸣生命降到 0 的瞬间进入战败画面。

### 3.1 主行动

| 主行动 | 效果 |
|---|---|
| 出手 | 打**相邻**站位上的一个对手、小怪或物件，造成 4 点伤害（杯戏师用杯子敲） |
| 架势 | 获得 4 点守护 |
| 道具 | 用道具袋里的一件道具（见 03） |

道具袋每场对戏开始时重置为固定内容，不用管理背包。

## 4 交换【定】

每回合一次（以后的形态和升级可以增加次数）。界面上有形态切换：「换位」「换物」。

### 4.1 换位（第一出解锁）

- 交换两个站位上的东西。可以是空站位（等于把东西挪过去）。
- 两个站位的距离（编号差）不超过**交换距离**：初始 2，可以用领悟升到 3。
- 可以包含阿鸣自己的站位。
- 不能选：两个都是空站位；任何一方是"重"的；任何一方是"隐身"的。

### 4.2 换物（第三出解锁）

- 交换两样东西的**持有物**。两边都必须拿着东西。
- **不看距离**，但两边都要看得见（不能是隐身的）。
- 例子：把阿鸣手里的空灯和老乔手里装满借来之光的灯笼对调。

### 4.3 选择与预览

1. 选形态 → 点第一个目标（能选的目标描边高亮，不能选的变暗，悬停时显示原因，例如"太重了，换不动"）。
2. 点第二个目标 → 进入**预览**：东西以半透明虚影显示在交换后的位置；所有意图箭头按新位置重新计算，每个站位上方显示"将受到 X 点"。
3. 再点一次或点「确认」执行；右键取消。
4. 如果这次交换会触发**反转**（见第 6 节），预览里额外显示金色的"反转"标签和效果说明。

## 5 意图【定】

- 每个对手、小怪头顶显示下一个意图：**图标 + 数字 + 编号 + 一根指向目标站位的箭头**。
- 目标是**站位**，不是人：意图在公开时就锁定了站位号（"打 → 槽 3"）。之后谁站在槽 3，谁就挨打。
- 意图类型：

| 类型 | 写法 | 结算 |
|---|---|---|
| 打 | 打 N → 槽 X | 槽 X 里的东西受到 N 点伤害；空站位则打空 |
| 移动 | 溜 / 躲 / 蹦 → 槽 X | 和槽 X 里的东西交换位置；槽 X 是重的东西则移动失败 |
| 规则动作 | 摸 / 吹灭 → 槽 X | 按对手的规则说明结算 |
| 交换 | 交换 槽 X ↔ 槽 Y | 只有序幕里失控的杯戏师会用 |
| 守护 | 守护 N | 获得守护 |

- **攻击会打到站在目标站位上的任何东西，包括攻击者自己**。把对手换到它自己瞄准的站位上，它就会打到自己（台下哄笑）。这是本作的基本玩法之一。
- 意图数字实时反映修正（例如守护、晕）。
- 阿鸣头像旁常驻显示"本回合将受到 X 点"（按当前站位计算）。

## 6 规则与识破【定】

### 6.1 水牌

- 有规则的对手，台口立一块**水牌**，上面是一句带空格的话，例如：「被他（　）过的东西会忘记（　），替他（　）。」
- 每个空格有两个来源：
  1. **对戏里**：规则第一次以某种方式生效时，对应的空格填上（锣声 + 字亮起 + 一句台词）。
  2. **查访词签**：查访时拿到的词签，开幕时自动飞进水牌对应的空格。
- 【定】**每条规则至少有一个空格只能在台上亲眼看到**才会填上，查访最多帮你填满其余的空格。这保证每场对戏都有"看懂"的过程。

### 6.2 识破

- 所有空格填满的瞬间：锣响、聚光灯打在水牌上、台下观众"哦——"，水牌整句亮起，台口盖一个"识破"的印章。
- 识破之后，某一次**特定的交换**会变成**反转**：预览时显示金色"反转"标签；执行时有专属演出和更大的效果。
- 同样的交换在识破之前也能做，但只有**基础效果**。
- 每场对戏反转只能触发一次；之后再做同样的交换只有基础效果。
- 识破后，杯戏师会朝反转的目标比划一下（"！"气泡），给一个温和的提示。

### 6.3 不识破也能赢【定】

对手的生命和伤害按"只用出手、架势和普通交换"也能打赢来设定。自动试玩必须证明这一点（见 architecture）。

## 7 胜负与援助

- 胜利：对手认输（谢幕）或序幕里月屑全部逃走。
- 战败画面：「再来一出」，从这场对戏开头重来。**已经填上的空格保留**（你已经看懂的东西不会忘）。
- 再来时可以勾选「援助」（可多选，随时可以在暂停菜单里关掉）：
  - **提示**：每回合杯戏师高亮一个推荐的交换；
  - **让一让**：对手生命 -30%。
- 没有任何永久惩罚。

## 8 排练

- 一个排练就是一个"一回合"的交换谜题，用和对戏完全相同的戏台规则。
- 布置好的戏台 + 公开的**环境意图**（漏雨、鹅啄、苹果车滚）+ 一个目标（"面粉袋不能湿"）。
- 你有规定次数的交换（大多是 1 次），有的排练也允许主行动。做完后点「开演」，环境意图按编号结算，然后判定目标。
- 成功：领悟 +1（每个排练只给一次），可以再玩但不再给领悟。
- 失败：画面倒回开演前，免费无限重来；失败 2 次后杯戏师比划一个提示。
- 随时可以点「重置」。

## 9 幕前查访

- 小镇画成一幅侧视布景（不是地图，不能走动），上面有 4–6 个可以点的人和东西。
- 点人：弹出头像对话 2–4 句；有些对话结束时给一张**词签**，飞进手账。
- 点东西：一句描述；有些给词签，有些给动机线索（谢幕时会用到）。
- 手账显示"还有 N 处没看"。随时可以点「去找他」离开；有没看的地方时会确认一次。离开后不能回来。
- 没有失败，没有时间限制。

## 10 岔路与路遇

- 对戏之前出现一张岔路牌，二选一：
  - **走大路**：打一场路遇小战（规则和对戏相同，没有水牌），胜利 +1 领悟；
  - **抄小路**：直接去对戏。
- 路遇战败：可以「再来」，也可以「绕开」（直接去对戏，不拿领悟）。

## 11 成长

### 11.1 形态（剧情推动）

| 形态 | 解锁 | Demo |
|---|---|---|
| 换位 | 第一出 | ✓ |
| 换物 | 第三出开场 | ✓ |
| 换态 / 换序 / 换则 | 以后的章节 | 只在文档里留位置 |

### 11.2 领悟（排练和路遇）

每出戏结束后在葛伦的铺子里花掉，见 [03-content.md](03-content.md) 第 8 节。数量固定，做完就没有了，不能刷。

### 11.3 印记（谢幕时对手送的）

- 让交换带上一点对方的味道（例如「惦记」：被你换过的物件会替你挡一次打）。
- Demo 里最多同时装 1 枚，在葛伦的铺子里更换。

## 12 存档

- 自动存档点：每出戏开始、每次进入查访、每个排练完成后、每场对戏开始前。
- 对戏中途退出：下次从这场对戏开头开始（已填的空格保留）。
- 读取失败：坏文件改名备份，回到标题，不崩溃。

## 13 边界情况清单

| 情况 | 处理 |
|---|---|
| 攻击的目标站位上站着攻击者自己 | 照样打，自己挨打 |
| 两个意图打同一个站位 | 按编号依次结算 |
| 移动意图的目标站位上是重的东西 | 移动失败，原地不动 |
| 意图公开时瞄准"阿鸣所在的站位" | 显示为具体站位号，之后不跟着阿鸣走 |
| 一个东西被换走后，它自己的意图 | 仍按公开时的站位号结算（它站在哪里不影响打哪里） |
| 交换后隐身的敌人所在站位变亮 | 立即现身，可以被选中 |
| 换物时一方没有持有物 | 不能选 |
| 识破后又做了一次同样的交换 | 只有基础效果 |
| 对手被晕 | 跳过它下一个意图；头顶显示"晕"，意图图标变灰 |
| 物件被打倒 | 站位变空；它身上的标记（手印等）一起消失 |
| 出手的相邻站位上没有可以打的东西 | 出手按钮变灰 |
| 序幕第 1 回合 | 还没有交换能力，交换按钮不显示 |
