### 5.2 第二出：学徒小偷阿扒

| 项 | 内容 |
|---|---|
| id | duel.thief |
| 对手 | 阿扒，生命 16；戏灵「黏黏手」 |
| 布置 | `[阿鸣 | 苹果筐 | 阿扒 | 铁锅 | 婆婆的摊位]` |
| 水牌 | 「被他（摸）过的东西会忘记（主人），替他（挡打）。」 |
| 意图循环 | 摸 → 相邻的一件没有手印的物件（两边都有时先左边；都有手印则改为偷袭） → 偷袭 4 → 阿鸣所在站位 → 溜 → 离阿鸣最远的不重的站位 → 偷袭 4 → 阿鸣所在站位 → 回到开头 |

**规则效果**

- **摸**：被摸的物件得到「手印」（物件上出现一个发光的小手印）。
- **挡打**：有手印的物件在阿扒相邻时，阿扒受到的攻击改由这件物件承受（包括他打到自己的那一下）。物件被打倒，手印跟着消失。
- **忘记主人**：有手印的物件不再"认"主人。

**空格来源**

| 空格 | 对戏里 | 查访词签 |
|---|---|---|
| 摸 | 他第一次摸到东西 | 布店老板 |
| 主人 | 第 2 个对手回合结束时，台下婆婆喊"那是我的筐子！" | 摊主婆婆 |
| 挡打 | 有手印的物件第一次替他挨打 | ——（只能在台上看到） |

**反转「物归原主」**

| | 触发 | 效果 |
|---|---|---|
| 基础（没识破） | 用换位把有手印的苹果筐换到婆婆的摊位旁边（槽 4） | 苹果筐的手印消失 |
| 反转（识破后） | 同上 | 苹果筐想起了主人，一筐苹果哗啦倒在阿扒头上：他受到 6 点伤害（不能被挡）、晕 1 回合；台上所有物件的手印消失 |

开局的第一个意图就会摸苹果筐，所以苹果筐（槽 2）和槽 4 的距离正好是 2，一次换位就能做到。

【待验证】玩家可以把阿鸣换到阿扒旁边、把有手印的筐子换开，从而一直不触发"挡打"，那么这个空格就永远填不上。用自动试玩调整布置和意图循环，目标：**大多数玩法在第 3 回合前看到一次"挡打"**。例如让"溜"的目标改成"有手印的物件旁边"。

**谢幕**：阿扒认输，送出印记「惦记」。

### 5.3 第三出：渡夫老乔

| 项 | 内容 |
|---|---|
| id | duel.ferryman |
| 对手 | 老乔，生命 24（D1 自动试玩校准，原初稿 20）；戏灵「借光人」 |
| 布置 | `[阿鸣（持：空灯） | 灯柱A（亮） | 渡船 | 灯柱B（暗） | 老乔（持：借光灯笼）]` |
| 开局亮暗 | 灯柱A 照亮槽 1–3；槽 4、5 是暗的 → 老乔隐身 |
| 水牌 | 「借走你（灯）里的（光），你就（看不见）他。」 |
| 意图循环 | 吹灭 → 最近的一盏亮灯柱（没有亮的就改为撑篙） → 撑篙 5 → 阿鸣所在站位 → 躲 → 离阿鸣最远的暗站位 → 回到开头 |

**规则效果**

- **吹灭**：那盏灯柱变暗，老乔灯笼里"借来的光"+1。
- **看不见**：老乔站在暗的站位时隐身（不能被出手、弹珠、交换选中）。
- **撑篙会现身**：老乔撑篙时要走到亮处，从撑篙开始到他下一个行动之前都看得见。

**空格来源**

| 空格 | 对戏里 | 查访词签 |
|---|---|---|
| 灯 | 他第一次吹灭灯柱 | ——（只能在台上看到） |
| 光 | 他第一次现身（撑篙），台上能看见他灯笼里装满的光 | 卖鱼大婶 |
| 看不见 | 你第一次想选中隐身的他，或第 2 个对手回合结束时阿鸣喊"他不见了！" | 赶考书生 |

**反转「光，还回去」**

| | 触发 | 效果 |
|---|---|---|
| 基础（没识破） | 用换物把阿鸣的空灯和老乔的借光灯笼对调（老乔必须看得见） | 阿鸣拿到亮灯（阿鸣的站位和相邻站位变亮）；老乔的灯笼空了，2 回合内不能隐身 |
| 反转（识破后） | 同上 | 借来的光一下子全飞回去：所有灯柱重新亮起；老乔被晃得眼花，受到 6 点伤害、晕 1 回合；**这场对戏剩下的时间他都不能隐身** |

其它解法：把亮着的灯柱换到他旁边照出他（例如第 1 回合把灯柱A和灯柱B对调：亮灯到了槽 4，照亮槽 3–5，他现身；他那一下"吹灭 → 槽 2"吹到的是一盏本来就暗的灯）；先架势挨他一篙，趁他现身时出手，或者把他换到他自己瞄准的站位上。

注意：换位和换物共用每回合 1 次的交换，同一回合不能既照亮他又换走他的灯笼。

**谢幕**：老乔认输，送出印记「微光」。
