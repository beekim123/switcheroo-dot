# 05 · 界面流程

## 1 画面规格【建议】

| 项 | 规定 |
|---|---|
| 逻辑分辨率 | **640×360**，整数倍放大，最近邻采样，多余部分黑边 |
| 字体 | Fusion Pixel 12px；大标题 24px |
| 面板 | 九宫格边框，不透明底色，不用渐变 |
| 操作 | 鼠标点击为主；右键取消；键盘快捷键为辅 |

## 2 画面流程

```text
启动 → 标题 → 戏单（继续 / 新游戏 / 选一出）
  → 插画页 → 幕前查访 → 排练选择 → 排练 ×2 → 岔路牌 →（路遇）→ 对戏 → 谢幕插画 → 写信 → 梦
  → 葛伦的铺子（领悟升级 / 换印记 / 出发）→ 下一出
Esc：暂停菜单（继续 / 援助开关 / 设置 / 回到戏单）
```

### 3.1 交换的操作

1. 点底部的形态按钮（「换位」/「换物」）或直接点一个可选目标（默认换位）。
2. 可选的目标描边高亮；不能选的变暗，悬停显示原因（"太重了，换不动""看不见他""距离超过 2"）。
3. 选了第一个目标后，第二个目标的可选范围随之更新（换位：距离以内的站位亮起）。
4. 选了第二个目标：进入预览。
   - 两样东西以虚影显示在交换后的位置；
   - 所有意图箭头按新位置重画，每个站位的靶标上显示"将受到 X"；
   - 会触发反转时，出现金色"反转"标签和一行效果说明；
   - 底部出现「确认交换」。
5. 再点一次第二个目标或点「确认交换」执行；右键取消。
6. 执行动画：两只杯子分别扣住两样东西 → 杯子在空中交叉飞过 → 掀开（约 0.6 秒）。

### 3.2 主行动的操作

- 出手：点「出手」，相邻的可打目标高亮，点目标执行。只有一个目标时直接执行。
- 架势：点就执行。
- 道具：点「道具」弹出道具袋（2 格），选道具，需要目标的再点目标。
- 每样行动执行前都有预览数字（目标头上"生命 16→12"）。

### 3.3 回合结算

- 点「结束」后，敌人按编号逐个行动：被执行的意图放大闪一下 → 行动动画 → 伤害数字弹出 → 观众反应。
- 按住鼠标 2 倍速。

## 4 排练画面

- 和对戏相同的戏台，但没有水牌、没有观众（换成"排练中"的小牌子和空座位）。
- 顶部显示目标（"面粉袋不能湿"）和剩余交换次数。
- 底部按钮：「开演」、「重置」。
- 成功：台下空座位里冒出葛伦，鼓掌，领悟 +1 飞进右上角。
- 失败：画面停在结算结果，0.8 秒后倒回开演前，出现"再来一次"。

## 6 葛伦的铺子

- 侧视插画背景（满墙齿轮）。左边是领悟升级列表（名字、效果、花费、剩余次数），右边是印记栏（1 格）和已有印记。
- 「出发」进入下一出的戏报。

## 7 操作一览

| 操作 | 鼠标 | 键盘 |
|---|---|---|
| 选目标 | 点击 | ←→ 移动选择，回车确认 |
| 切换形态 | 点按钮 | Tab |
| 出手 / 架势 / 道具 | 点按钮 | A / G / I |
| 取消 | 右键 | Esc |
| 结束回合 | 点按钮 | E |
| 翻页、跳过台词 | 点击 | 空格 / 回车 |

## 8 反馈与可读性【定】

- 每次选中、取消、交换、出手都有声音和动画反馈；不能选时有轻微的"不行"音效和抖动。
- 意图箭头和靶标必须在任何时候都清楚：多个意图打同一站位时，靶标上叠放编号。
- 意图图标形状不同（不只靠颜色），色弱也能分清。
- 伤害数字红、守护蓝、回复绿，描边像素大字。
- 设置：主音量、音乐、音效、文字速度、结算速度、窗口倍数、全屏；援助开关也在暂停菜单里。

## 9 调试功能（只在调试版）

- F1 调试面板：跳到某一出的某一步；直接填满水牌；对手生命设为 1；给领悟；开关自动操作（调用自动试玩策略）。
- F2 所有台词立即显示（检查文字溢出）。
