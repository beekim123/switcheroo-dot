# 04 · 戏台上的叙事（炉石冒险式）

【定】**不做地图移动和俯视探索。** 故事全部在"戏单 + 插画页 + 查访布景 + 戏台"上讲。

参考《炉石传说》冒险模式的**表现手法**：旁白人物、插画分镜页、对手登场、对局中的台词、可以点的场景装饰。本作把"牌桌"换成"戏台"：两个戏灵相遇，四周就搭起一座戏台，有幕布、水牌和台下看热闹的人。只学手法，不复刻它的界面图形、名字和文本。

## 1 叙事组件总览

| 组件 | 在哪出现 | 做什么 |
|---|---|---|
| 戏单（冒险书） | 标题之后 | 墙上贴着一张张戏报，每张是一出戏。第一到第三出可以选，第四出「钟塔镇」的戏报被一张"下回分解"的纸条盖住 |
| 插画页 | 序幕、每出的开场与谢幕、形态解锁、结尾 | 葛伦爷爷讲古的口吻，一页一幅像素插画 |
| 信 | 每出谢幕后 | 信纸版式，阿鸣写给麦朵，玩家挑最后一句；纸鹤叼着信飞走 |
| 梦 | 写信之后 | 银月色调的一页插画：麦朵在遗迹那边的生活 |
| 幕前查访 | 每出开头 | 小镇的侧视布景，点人问话、点东西查看，拿词签 |
| 开幕 | 每场对戏开始 | 幕布落下又升起、戏报式登场卡、水牌立起、词签飞进空格 |
| 台上台词 | 对戏、排练 | 阿鸣、杯戏师（表情气泡）、对手、葛伦（台侧喊话） |
| 台下观众 | 对戏 | 前排一排镇民剪影，对台上发生的事做一个字的反应 |
| 识破与反转 | 对戏 | 锣、聚光灯、水牌亮起、反转专属演出 |
| 谢幕 | 对戏胜利 | 两边鞠躬、幕布合上，然后是对手的心事 |
| 戏台彩蛋 | 对戏、排练 | 幕布绳、脚灯、提词小窗、背景里的双月 |

## 2 插画页

### 2.1 规格【建议】

- 书页边框里放一幅 **320×180** 的插画，下方旁白框（每页最多 2 行、50 字）。
- 插画由**图层拼成**：背景 + 人物大立绘 + 道具 + 前景，每层可以有 2–4 帧小循环（风车转、灯火跳、纸鹤扇翅膀），也可以整数像素慢速平移。
- 旁白默认是葛伦（不显示头像，文字前加一个小小的烟斗图标，表示"老人在讲"）。
- **信**用信纸版式：泛黄信纸，左上角盖一个纸鹤邮戳，字是深蓝色。
- **梦**用换色表导出的银月单色版本。
- 点击、空格、回车翻页；右上角"跳过"。

数据格式与另外两个项目相同：`content/story/pages.json`，每页 `layers` + `speaker` + `text`，可带 `when` 条件；信的结尾句由 `letter_choice` 字段引用玩家的选择。

## 3 开幕与谢幕

### 3.1 开幕（约 4 秒，第二次起可跳过）

1. 幕布从上方落下，遮住查访布景；锣鼓点"仓——仓仓"。
2. 幕布中央显示戏报式登场卡：「今夜上演：《苹果集市》——学徒小偷阿扒 对 杯戏师」。
3. 幕布升起：戏台上已经摆好站位。对手和他的戏灵站在台上，阿鸣和杯戏师从左侧上台。
4. 对手说一句，阿鸣回一句（气泡）。
5. 台口的水牌立起来，上面是带空格的规则句子；查访拿到的词签一张张飞进对应的空格（每张一声木鱼）。
6. 对手公开第一个意图，开始第一回合。

| 对手 | 开幕台词 | 阿鸣回应 |
|---|---|---|
| 阿扒 | 「你的东西，我摸一下就是我的了！」 | 「那你先摸摸看。」 |
| 老乔 | 「天黑了，小孩子回家去。」 | 「把镇上的灯还回来，我就回。」 |

序幕战没有登场卡：幕布落下时，失控的杯戏师已经在台上空乱飞。

### 3.2 谢幕（约 3 秒）

1. 对手生命降到 0：对手坐倒在地，戏灵垂下手。
2. 台下观众鼓掌；阿鸣和杯戏师、对手和他的戏灵一起鞠躬（对手的戏灵鞠完躬，化成一点光回到主人身上）。
3. 幕布合上，接谢幕插画页（对手的心事）。
4. 对手送出印记：一张小卡从幕布缝里递出来。

## 4 识破与反转【定·体验】

识破是本作最重要的高光时刻，每次都完整播放（约 2 秒，不可跳过但可以点击加速）：

1. 最后一个空格填上的瞬间，画面定住半秒。
2. 一声大锣，聚光灯从上方打到水牌上，整句话亮起来。
3. 台下观众："哦——"
4. 水牌右下角盖一个朱红色的"识破"印章（像素字，印章样式，**不是**拟声大字）。
5. 杯戏师朝反转的目标比划一下（"！"气泡），恢复操作。

反转的专属演出：

| 反转 | 演出 |
|---|---|
| 物归原主（阿扒） | 苹果筐抖一抖，"想起来了"，猛地一歪，一筐苹果哗啦倒在阿扒头上；苹果骨碌碌滚回婆婆的摊位；台下婆婆："回来啦！" |
| 光，还回去（老乔） | 老乔灯笼里的光化成一串萤火，一盏一盏飞回灯柱，灯柱依次亮起；最后一盏照在老乔脸上，他抬手挡眼；台下："亮了！" |

## 5 台上台词与观众

### 5.1 规则【建议】

- 说话人：**阿鸣**（台上头顶）、**杯戏师**（只用表情气泡：！ ？ ♪ …… 和一个鞠躬动作）、**对手**、**葛伦**（序幕和第一出从台侧喊话，气泡从屏幕左边缘冒出）、**观众**（台下前排剪影）。
- 气泡不挡操作，显示 2.5 秒 + 每字 0.08 秒；同一个说话人同时只有一个气泡；普通台词全局冷却 4 秒；观众反应不受冷却限制，但同一种反应 6 秒内只出一次。
- 有逐字说话音（每人一种），不做配音。

### 5.2 触发事件表

`content/story/banter.json`，记录格式：`{ id, event, speaker, when, lines[], once, chance, priority }`。

| event | 说明 |
|---|---|
| duel_start / turn_start | 开幕后 / 你的回合开始 |
| swap_done | 你做了一次交换，带形态 |
| self_hit | 有东西打到了自己 |
| redirect_hit | 敌人的攻击打到了别的敌人或物件 |
| big_hit | 一次造成 6 点以上伤害 |
| dodge | 一个瞄准阿鸣的攻击因为交换打空了 |
| blank_filled | 水牌填上一个空格，带空格 id |
| exposed | 规则识破 |
| reversal | 反转发动 |
| player_low_hp | 阿鸣生命第一次低于 30% |
| foe_low_hp | 对手生命第一次低于 30% |
| idle | 20 秒没有操作 |
| victory / defeat / retry | 胜利 / 战败 / 再来一出 |
| inspect | 查访时点了某个人或东西 |

## 6 幕前查访

- 布景是一张 640×360 的侧视场景，像一出戏的舞台布景（镇子的房子、摊子、渡口），**不是可以走动的地图**。
- 可以点的人和东西悬停时描边高亮，旁边冒一个小"？"。
- 点人：画面下方弹出对话框（左边 48×48 头像），2–4 句；拿到词签时，一张小纸签从对话框飞进右上角的手账，手账抖一下。
- 点东西：对话框里是一句描述，不显示头像。
- 手账打开后：左页是已拿到的词签，右页是"还有 N 处没看"和已知线索。
- 右下角「去找他」按钮。

## 7 写信

1. 信纸从下方滑上来，正文逐字出现（3–4 行，固定）。
2. 最后一行空着，下面出现 3 个结尾句按钮。
3. 选一句后，那句话写进信里，信纸叠起来，纸鹤叼起信从窗口飞走（小演出，配纸鹤扇翅膀的音效）。
4. 选择记入存档 `letters[n]`。
