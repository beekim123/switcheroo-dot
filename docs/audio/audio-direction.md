# 音乐与音效

## 1 原则【定】

- **所有声音都由仓库里的代码合成。** 源数据是文字（音符、音色参数、包络）；不用录音、不用外部采样、不用任何 AI 音乐/语音服务、不用现成旋律。
- **确定性**：同一份源数据，每次合成逐样本一致。噪声只用带固定种子的伪随机数。
- 做法沿用 <https://github.com/beekim123/rpg2d-dot> 的 `resources/audio/synth.ts`：纯 TypeScript 合成器 → Node 离线导出 WAV → 数值检查 → 游戏只播放 WAV。可以参考或改写它的代码，**旋律必须为本作重新创作**。
- 锣鼓用合成的锣、钹、板、木鱼来做，节奏可以借鉴传统戏曲锣鼓点的**组织方式**（开场、收尾、紧打慢打），但具体节奏型自己写，不照搬任何现成曲牌或唱段。

## 2 管线【建议】

```text
resources/audio/cues/*.ts → synth.ts（renderCue）→ tools/resources/audio-pack.ts
  → resources/audio/export/*.wav + manifest.json（提交）→ npm run sync → godot/resources/audio/
```

| 项 | 规定 |
|---|---|
| 格式 | 单声道 PCM16 WAV |
| 采样率 | 音乐 22050 Hz，音效 44100 Hz |
| 单文件 | 小于 2 MB |
| 响度 | 音乐 RMS −20 ±2 dBFS，音效 −18 ±3 dBFS，峰值 ≤ −1 dBFS |
| 循环 | 首尾样本归零，接缝检查通过 |
| Godot 导入 | 关闭有损压缩；音乐前向循环 |

`npm run audio:check`：双次合成逐样本比较，报告 SHA-256、峰值、RMS、接缝。**数值通过不等于好听**，每首曲子都要在游戏里实际听过并记录听感。

### AudioService（Godot 端）

- 第一次点击后启声；最多 6 个音效、2 个音乐播放器交叉淡化（0.6 秒）。
- 三条总线（主、音乐、音效），末端限幅 −1 dB。
- 识破时音乐**压低 0.8 秒**（让锣声出来），然后恢复。

## 3 音色【建议】

热闹的乡间戏班 + 芯片音乐。

| 音色 | 做法 | 用途 |
|---|---|---|
| 拨弦 | Karplus-Strong | 像月琴、三弦，主旋律与伴奏 |
| 笛子 | 正弦 + 少量谐波 + 颤音 | 抒情段、信、梦 |
| 柔和方波 | 25% / 50% 占空比 + 低通 | 对戏旋律 |
| 三角波 | — | 低音 |
| 锣 | 多个非整数倍频率的正弦 + 慢衰减 + 轻微下滑 | 开幕、识破、谢幕 |
| 钹 / 镲 | 高通滤波的种子噪声，短 / 长两种包络 | 节奏 |
| 板 / 木鱼 | 很短的高频噪声 + 共振 | 意图提示、词签、节拍 |
| 铃 | 双算子 FM | 梦、纸鹤 |

## 4 主题动机「换月谣」【建议】

全游戏共用一个动机，意象就是"交换"：**第二句是第一句的两两对调**。下面是原创示例（4/4 拍，数字为八分音符个数，每小节合计 8），可以改写，但要保留"后一句是前一句两两对调"的结构，并在 `resources/audio/README.md` 写清最终版本：

```text
A1 | C5×2 E5×2 G5×2 A5×2 |   第一句
A2 | E5×2 C5×2 A5×2 G5×2 |   两两对调
A3 | F5×2 A5×2 G5×1 E5×1 D5×2 |
A4 | D5×2 E5×1 G5×1 C5×4 |   落回主音
```

- 对戏曲里，动机节奏化、加锣鼓；梦和信里，用笛子慢慢地吹第一句，第二句不吹（"还没换回来"）。
