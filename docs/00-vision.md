# 00 · 愿景与 Demo 范围

## 1 一句话

**《掉包记》**（暂定名）：换月夜，你心里的「戏灵」第一次走出来，一出手就把最好的朋友"换"到了远方。你带着这个只会"交换"的小戏法师上路，在一座座小镇的戏台上，和其他觉醒者斗智对戏：看懂对手的怪规则，用一次巧妙的交换把它反过来。最后，把朋友换回来。

> 一个能力，越用越多用法。

## 2 相对原方案的调整

| 原方案 | 现在 | 理由 |
|---|---|---|
| 术语「心象」 | 「**戏灵**」：每个觉醒者心里走出来的，是一个会一门戏法的小戏子 | 原方案已经建议避开"替身"。"心象"又容易让人联想到 Persona 的"内心的另一个自己"。"戏灵"给了本作自己的说法 |
| 对决只是回合制战斗 | **对决就是一出戏**：两个戏灵相遇时，四周会搭起一座看不见的戏台，有幕布、台口的水牌（写对手的规则）、台下看热闹的镇民 | 炉石冒险模式的"牌桌即场景"，在这里换成戏台。舞台感也让"一排 5 个站位"显得天经地义 |
| 调查是俯视小场景 | **幕前查访**：小镇画成一幅侧视布景，点人问话、点东西查看，拿到的「词签」会预先填进对手规则的空格 | 用户要求不做地图移动 |
| 训练是练习委托 | **排练**：一个回合就能解开的交换小谜题，用的是和对决同一套戏台规则 | 少做一套系统；谜题做完就没有了，不会变成刷 |
| 路上遭遇：看得见、可绕开的战斗 | 对戏前二选一：「走大路」打一场小遭遇（多拿一点领悟）或「抄小路」直接去 | 没有地图，用一张选择牌表达"可以绕开" |
| 章节之间没有固定的叙事形式 | 旁白是师父葛伦爷爷回忆往事；每出戏结尾，阿鸣给麦朵**写一封信**；夜里梦见麦朵那边的生活 | 炉石式旁白；信件让"把朋友换回来"这条主线每章都被提起一次 |
| 体量 8 章 | Demo 只做**第一到第三出**（解锁「换位」「换物」两个形态） | 交接文档的建议范围，先验证核心玩法 |

核心玩法全部保留：一个固定可用的交换能力（不用牌组）；一排 5 个站位，敌人攻击指向站位，谁站在那里谁挨打；意图公开；交换前先预览；对手规则写成带空格的句子，填满后「识破」，特定的交换变成反转技；不识破也能赢；剧情推动形态进化，排练给小升级，印记改变手感。

## 3 设计支柱【定】

1. **一个能力，越用越多用法**：主角只有一个"交换"。成长是"能换的东西越来越多"，而不是学会更多招式。
2. **斗智反转**：每个对手都有一条怪规则。看懂它、用一次交换把它反过来，是本作最爽的时刻。
3. **看得见再动手**：敌人意图（打哪个站位、打多少）全部公开；交换之前预览谁会挨打；规则句子摆在台口。
4. **不识破也能赢**：识破是"可选但想做"的奖励，不是卡关的谜题。稳妥打法（架势 + 出手）一定能赢，只是慢一些。
5. **故事在戏台上讲**：戏单、开幕、台口水牌、台下观众、谢幕（见 [04-storytelling.md](design/04-storytelling.md)）。不做地图探索。
6. **原创边界**（见第 7 节）。

## 4 目标体验

| 时刻 | 玩家应该感到 |
|---|---|
| 序幕 | 戏灵失控，眼睁睁看着麦朵被换走：揪心 |
| 第一次自己交换 | "原来换个位置，挨打的就换了人！" |
| 敌人打到自己 | 把对手换到它自己瞄准的站位上，它一棍子敲在自己头上：台下哄堂大笑 |
| 查访 | 问了两个人，水牌上已经填好两个字："被他（摸）过的东西会忘记（主人）……" |
| 识破 | 锣一响，水牌亮起，一次交换让苹果筐自己滚回婆婆身边，砸了小偷一下：爽 |
| 谢幕 | 对手其实只是寂寞、只是想保护女儿，"原来是这样" |
| 写信 | 每一出结尾给麦朵写一封信，挑一句话做结尾 |

基调：俏皮、温暖、有一点江湖戏班的热闹，偶尔沉重。全年龄：对手被打败是"认输""下台"，不是死亡。

## 5 Demo 范围【定】

| 项 | 内容 |
|---|---|
| 章节 | 第一出「风车坡」（序幕 + 教学对戏）、第二出「苹果集市」（学徒小偷阿扒）、第三出「灯笼渡」（渡夫老乔） |
| 形态 | 换位（第一出）、换物（第三出） |
| 时长 | 40–55 分钟 |
| 内容量【建议】 | 对戏 3 场（2 场有规则）；排练 6 个；路遇小战 2 场；查访场景 3 个；小怪 3 种；物件约 10 种；印记 2 枚（只装得下 1 枚）；领悟升级 4 种 |
| 平台 | macOS 本机运行；Web 导出可选 |
| 操作 | 鼠标点击为主，键盘快捷键为辅 |

**Demo 要回答的问题**（详见 [plan/playtest.md](plan/playtest.md)）：
1. 识破规则在普通难度下是"可选但想做"，还是变成卡关谜题？
2. 一排 5 个站位能不能表达出换位的乐趣，又不变成战棋计算？
3. 没有牌组，战斗还有没有足够的变化？
4. 戏台包装和信件叙事有没有让人想看下一出？

## 6 刻意不做【定】

原方案清单，原样保留：

- 牌组和抽牌
- 召唤单位
- 多人队伍
- 经验值和等级
- 属性克制表
- 随机遇敌

Demo 阶段额外不做：

- 第四出及以后（只放一张上锁的戏单）
- 「换态」「换序」「换则」三个形态（只在文档里留位置）
- 装备、商店
- 多存档槽、成就

原方案的备选"把主角行动做成每回合 3 张小手牌"，默认不做。

## 7 原创边界【定】

- 不使用"替身""替身使者""心象"等说法；戏灵不以歌曲名、乐队名命名。
- 不使用 JoJo 式的标志性姿势、拟声大字特效、"使者互相吸引"之类的原作设定。识破的演出用中式戏台的锣、灯光、水牌，不用日式拟声字。
- 交换能力、换月夜、朋友被换走的开场、戏灵与戏台都是原创设定。
- 《炉石传说》只参考叙事表现手法，不复刻界面图形、名字、文本。

## 8 术语（玩家可见，最多 5 个）【定】

| 术语 | 含义 |
|---|---|
| 交换 | 杯戏师的能力，每回合一次；目前有两种：「换位」换两个站位上的东西，「换物」换两个人手里拿的东西 |
| 意图 | 对手下回合要做什么、打哪个站位，头顶公开显示 |
| 守护 | 先替你挡伤害，你的回合开始时清零 |
| 规则 | 对手戏灵的怪规则，写在台口的水牌上，有空格 |
| 识破 | 规则的空格全部填满；这时某一次特定的交换会变成反转 |

「领悟」（排练得到，用来换小升级）和「印记」（谢幕时对手送的，改变交换的手感）在第一次出现时用一句话说明，不当作需要记的术语。
