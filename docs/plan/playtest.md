# 试玩验证计划

Demo 的目的就是回答下面这些问题。每个问题都有：怎么测、合格线、不合格时先改什么。合格线是初稿，用户可以改。

## 1 自动试玩与求解的目标区间（D1 起每次改数值都要跑）

| 指标 | 目标 |
|---|---|
| 6 个排练都有解（求解器） | 100% |
| 稳妥策略：三场对戏胜率 | 100%（可以用道具） |
| 稳妥策略：平均回合数 | 阿扒 ≤ 10，老乔 ≤ 12 |
| 一步前瞻策略：平均回合数 | 阿扒 5–7，老乔 6–8 |
| 一步前瞻策略：识破率 | ≥ 80% |
| 一步前瞻策略：识破后 2 回合内发动反转的比例 | ≥ 60% |
| 不交换策略 | 明显慢于一步前瞻（回合数多 50% 以上）或会输：证明交换有用 |
| 每个空格在一步前瞻策略下的平均填上回合 | ≤ 第 3 回合 |

## 2 用户试玩要回答的问题

### Q1 识破是"可选但想做"，还是卡关的谜题？

- 观察：有没有在看水牌；填上空格时的反应；识破后能不能自己找到反转（不靠提示）；有没有在对戏里卡住超过 1 分钟。
- 合格：两场有规则的对戏里，至少一场自己识破并用出反转；没有一场是因为"不知道怎么赢"而卡住。
- 不合格先改：空格填得更早、更显眼；识破后杯戏师的提示更直接；对手生命更低。

### Q2 5 个站位能表达出换位的乐趣，又不变成战棋计算吗？

- 观察：每回合思考时间；有没有反复预览、来回取消；问"有没有觉得在算数学题"。
- 合格：大多数回合在 20 秒内做完；能说出至少一次"换完之后很爽"的时刻（打到自己、互相打、躲开）。
- 不合格先改：减少场上东西的数量；预览更清楚；对手意图更少、更直白。

### Q3 没有牌组，战斗有没有足够的变化？

- 观察：问"三场对戏感觉像不像同一件事"。
- 合格：用户能说出三场的不同（教学的乱换、阿扒的手印、老乔的暗处）。
- 不合格先改：每场加一个独特物件；让换物更早出现。

### Q4 查访和排练有没有用？

- 观察：查访有没有看完；排练有没有觉得多余；问"查访拿到的字有没有帮到你"。
- 合格：大多数人看完查访；排练不被评价为"浪费时间"。
- 不合格先改：查访拿到的词签更显眼地飞进水牌；排练更短或可跳过。

### Q5 戏台包装和信件，有没有让人想看下一出？

- 观察：插画页、信有没有跳过；结尾回信时的反应。
- 合格：插画页跳过率低于 30%；想玩第四出的评分 ≥ 3.5/5。
- 不合格先改：插画更短；信件更有个人色彩（三选一的句子更有区别）。

### Q6 有没有"像 JoJo 换皮"的感觉？

- 观察：问"这个游戏让你想到了什么作品"。
- 合格：没有人第一反应说 JoJo；如果有，记下是哪个元素引起的联想。
- 不合格先改：调整引起联想的那个元素（造型、台词、演出）。

## 3 试玩后问卷（给用户）

1. 一共玩了多久？
2. 三场对戏里哪一场最好玩？为什么？
3. 有没有自己识破规则？识破的那一刻感觉怎么样？
4. 有没有哪一次交换让你觉得"太妙了"？
5. 有没有哪一回合想了很久、或者觉得在算数学题？
6. 查访和排练，有没有哪一个觉得多余？
7. 写信时你选了哪几句？
8. 这个游戏让你想到了什么作品？
9. 最想吐槽的一个地方？
10. 最想保留的一个地方？
11. 如果有第四出，想不想继续玩？（1–5 分）
12. 整体好玩程度（1–5 分）
