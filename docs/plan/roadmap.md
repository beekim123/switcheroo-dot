# 里程碑

按顺序做，不按日期。每个里程碑结束时，游戏都能从标题玩到当前进度的结尾。验收不通过就不进入下一个。

## D0 · 地基

目标：所有管线都通一遍，Godot 能启动。

- 按 [repository-layout.md](../tech/repository-layout.md) 建好全部目录、`.gitignore`、`package.json` 脚本。
- 美术：`palette.json`、`lib/png.mjs`、`lib/pixel.mjs`、`tools/resources/art.mjs`；画 1 个字符画素材（杯戏师待机）和 1 个程序素材（戏台框架）；build/verify/sheet 跑通。
- 声音：`synth.ts`、2 个音效（`sfx.cup_down`、`sfx.cup_up`）、1 声锣、1 段 8 秒测试旋律（换月谣的前两小节）；导出 WAV、`audio:check` 跑通。
- 内容：`content/registry.json` + 最小 `duels.json`；`content:check` 跑通。
- 同步：`npm run sync` / `sync:verify`。
- Godot：工程设置、AssetCatalog、AudioService、字体；标题画面显示戏台框架和杯戏师，点击发声。
- 测试：无界面测试框架 + 1 个规则测试。

**验收**：`npm run check` 全部通过；标题画面截图（3 倍放大）文字清楚、像素不糊。

## D1 · 规则可玩（灰盒）

目标：用简单的代码画灰盒图，完整玩通三出戏，并用自动试玩和求解器证明可玩。

- 戏台规则全部实现：站位、属性、亮暗、主行动、换位、换物、意图（锁定站位、打到自己）、回合顺序、胜负、援助。
- 两个对手的规则钩子、水牌与识破、反转（基础/反转两档）。
- 序幕教学脚本。
- 6 个排练 + 求解器；2 场路遇；岔路。
- 查访（灰盒布景，可点区域用色块）、词签、手账。
- 葛伦的铺子：领悟升级、印记。
- 插画页、信、梦先用纯文字页代替（信的三选一要能选）。
- 存档。
- 自动试玩三种策略与报告。

**验收**：
- 全部规则测试和边界情况测试通过；求解器证明 6 个排练都有解；
- 稳妥策略三场对戏胜率 100%；
- 报告里每个空格都会在合理回合内被填上（见 playtest）；
- 自己从标题玩到 Demo 结尾一遍，记录实际时长。

## D2 · 叙事与表现

目标：故事在戏台上讲，画面和声音达到 demo 质量。

- StoryPlayer 和全部插画页（含信纸版式、梦的银月换色）；开幕、谢幕、识破、两种反转的专属演出；BanterDirector（台词、杯戏师表情、观众反应）；戏台彩蛋；写信与纸鹤演出。
- 全部正式像素美术（替换灰盒）：戏台、3 块布景、3 幅查访布景、人物、对手与戏灵、小怪、物件、界面、插画。
- 全部音乐、锣鼓短乐句、音效、说话音。
- 设置菜单。

**验收**：
- `npm run shots` 整套截图自己逐张看过，美术自查清单通过；
- `audio:check` 通过，每首曲子在游戏里听过并写下听感；
- 从标题玩到结尾，没有占位图、没有静音的操作、没有文字溢出。

## D3 · 试玩版

- 根据自动试玩和自己试玩调整：对手生命、意图循环、空格触发时机、交换距离。
- 导出 macOS 版（Web 可选）；写一页试玩说明；整理问卷。
- 已知问题写进 backlog。

**验收**：导出包在干净机器上能打开并玩到结尾；试玩说明和问卷就绪；打标签 `demo-1`。
